# Квіткова комора — локальний каталог насіння

Невеликий застосунок на TypeScript + React. Серверної частини, акаунтів і бази даних немає. Доступні локальний каталог у `localStorage` браузера та режим перегляду онлайн-каталогу з опублікованої Google Таблиці.

## Запуск

Потрібен встановлений Node.js (рекомендовано актуальну LTS-версію).

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай `http://localhost:5173`).

## Збірка

```bash
npm run build
```

Готові статичні файли будуть у `dist/`. Їх можна відкрити/розмістити як статичний сайт; серверна логіка не потрібна.

## Можливості

- Перегляд карток насіння та повної інформації про кожну позицію з галереєю фото, пошук і фільтр категорій.
- П'ять кольорових тем інтерфейсу, включно з висококонтрастною темною темою; вибір зберігається у браузері.
- Додавання, редагування, копіювання та видалення позицій. Мітки «Мало залишилось» і «Топ продажів» задаються вручну; складність вирощування має три рівні (легкий, середній, складний), а старі записи без рівня вважаються легкими. Рівень складності доступний як окремий фільтр і показується лише в деталях.
- Основні налаштування (адреса отримувача, тема листа, URL сайту й таблиці Google, чат Telegram, Google Fonts, список категорій і необов’язковий банер) зберігаються у `public/app-config.json`. Банер задається об’єктом `banner` з полями `imageUrl`, `text`, `linkUrl` та `alt`; потрібне хоча б одне з полів `imageUrl` або `text`. URL банера мають використовувати HTTPS. Наприклад: `"banner": { "imageUrl": "https://example.com/banner.jpg", "text": "Новинки сезону", "linkUrl": "https://example.com", "alt": "Новинки насіння" }`. Якщо `banner` відсутній або дорівнює `null`, банер не показується. Цей JSON попередньо завантажується браузером і читається під час запуску застосунку; після зміни налаштувань оновіть опублікований `app-config.json`. Файл є публічним і не повинен містити секретів.
- Кошик із вибором фасування, кількістю в межах наявного залишку, підрахунком суми та локальним збереженням. Замовлення можна підготувати через електронну пошту (із заповненим отримувачем, темою й текстом листа) або Telegram (копіювання тексту й відкриття чату). Для замовлень поштою покупець також може вказати бажаний спосіб зв'язку (Telegram/Viber) і номер телефону.
- Назва, сорт, латинська назва, українські й англійські назви-синоніми (також враховуються в пошуку), кольорові композиції з кількох атомарних кольорів (українська назва та HEX-код, із підказками вже наявних кольорів), необов'язкова таксономія (родина, підродина, триба, рід), категорія (зокрема дворічники й помідори), короткий та основний описи, основні й другорядні теги, висота, ширина, вазостійкість, умови та поради щодо зрізу й поради щодо збору насіння, морозостійкість, вільні поля стійкості до весняних та осінніх приморозків і чистоти (відповідності сорту), кількість днів до достигання та період цвітіння з точністю до декади місяця або завершенням «до морозу». Період висіву підтримує кілька інтервалів із визначеними декадами початку й кінця, способом висіву (на розсаду або прямо у ґрунт), необов'язковою позначкою «Рекомендовано», описом складності, додатковим описом лише в деталях і позначенням, чи буде цвітіння в рік посіву. Для освітлення можна обрати повне сонце, напівтінь або тінь чи ввести власний варіант. Кожне фото може мати дату, короткий опис і повний опис, що розгортається при натисканні на короткий. Є кілька варіантів фасування з окремими цінами й залишком у порціях. Для тегу «На зріз», періоду цвітіння та висіву є окреме оформлення. Під час додавання тегів доступні підказки наявних значень, але можна створити й власні. Фільтрування доступне за категорією, таксономією й тегами.
- Експорт/імпорт каталогу у JSON або CSV для резервної копії чи перенесення на інший комп'ютер; CSV можна також скопіювати в буфер обміну. Кожен запис повинен містити `priceOptions` — список фасувань із ціною та залишком; застарілий одиночний формат `price`/`quantity`/`unit` не підтримується.
- Перемикання між локальним каталогом (редагування дозволено) та онлайн-каталогом із Google Таблиці (редагування й імпорт вимкнені). При переході з онлайн у локальний режим поточний онлайн-знімок зберігається у локальний каталог. Режим запам'ятовується в браузері.
- Приклади кількох позицій, які можна змінити або видалити.

## Важливо

Локальні дані каталогу й кошика зберігаються тільки у конкретному браузері й профілі користувача. Очищення даних сайту/браузера може їх видалити — регулярно користуйтеся кнопкою **Експорт**. Онлайн-каталог доступний лише для перегляду; його завантаження потребує інтернет-з'єднання та дозволу CORS для таблиці з боку Google. Перехід з онлайн у локальний режим замінює локальні дані поточним онлайн-знімком. Це каталог із локальним кошиком, а не повноцінний інтернет-магазин: поштовий клієнт і чат Telegram відкриваються для ручного надсилання замовлення; оплата онлайн не реалізована. Фото додаються за URL; локальне завантаження файлів не реалізовано. Старі записи з одним фото залишаються сумісними.
